# ADR 0005 — Federation Assistant architecture reservation

- **Status:** Reserved
- **Date reserved:** 2026-07-29
- **Scope:** `thehub-pr`
- **Purpose:** Preserve the accepted ADR numbering sequence while the Federation Assistant architecture record is finalized.

ADR number 0005 is reserved for the Federation Assistant architecture decision that defines the Assistant-to-Control-Plane contract, approval model, policy enforcement, tool receipts, abstention behavior and certified-snapshot retrieval boundary.

This reservation contains no runtime decision and authorizes no implementation. It must be replaced by the full accepted ADR 0005 before any Assistant runtime or tool-execution work depends on ADR 0006.
