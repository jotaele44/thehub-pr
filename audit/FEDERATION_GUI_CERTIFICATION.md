## Vector C — canonical product standard

The current shared package is `@pr-federation/react` `0.4.1`. It already separates presentation tone from operational, workflow, evidence-tier, confidence, provenance, freshness and async-state axes.

### C-001 — semantic axes incomplete for forensic certification

**Severity: P1 / OPEN**

The canonical package does not yet encode the required epistemic axis:

`FACT | COMPUTED | BINDING | INFERENCE | ASSUMPTION | HYPOTHESIS | UNKNOWN`

or the complete certification axis:

`PASS | FAIL | OPEN | BLOCKED | PROVISIONAL | AUDIT_ONLY | NONCANONICAL | CANDIDATE_NOT_IDENTITY | UNRESOLVED | SUPERSEDED`

Until those are explicit canonical semantics, producer-local representations can silently diverge.

### B-001 — package adoption not closed

**Severity: P2 / OPEN**

Six of seven GUI repositories consume the shared React package; SpiderWeb does not. This is a package-convergence finding only. It is not evidence that SpiderWeb lacks federation-compatible tokens or that its current visuals are incorrect.

### B-002 — package versions not converged

**Severity: P2 / OPEN**

Consumers span `0.3.0`, `0.4.0` and `0.4.1`. Version equality is not itself proof of visual or semantic equivalence, but the skew prevents a single package contract from being assumed federation-wide.
